Retro TV

Turns the Internet Archive into a retro-video library and live channels inside Jellyfin. Video streams direct from the Archive at play time — nothing is downloaded in Stage 1.

Where .strm / .nfo / poster files and catalog.json go. On Dayz this is F:\IA-Channels\ — add that folder to Jellyfin as a Movies library named "Retro TV".
Written into catalog.json; the Jellyfin library keeps this name.
Politeness to archive.org. The builder backs off on 429/503 regardless.
Uncheck to build the public-domain tier only. The user-uploaded tier is never presented as public domain.
The theme applies to the guide page (Stage 2) and this page's accents. No restart needed.

Weather channel (Stage 2)

Default 05773 (Wallingford, VT). Change it, press "Resolve zip", and check the place name below before saving.
Weather data by Open-Meteo.com (free, no key).
Turn the guide off here to stop the channels without uninstalling. The guide page lives at /RetroTv/Guide on this server.

Live channel streams

Full path to the ffmpeg binary used to stitch channel streams. Leave blank to use "ffmpeg" from the PATH. On Dayz this is F:\Jellyfin\Server\ffmpeg.exe (Jellyfin's bundled ffmpeg). NVENC is used automatically when the ffmpeg reports h264_nvenc, otherwise the software encoder.
Font file for the weather channel slate. Leave blank to auto-detect (DejaVu Sans on Linux, Arial on Windows). Without a font the weather channel lists in the guide but cannot stream.

Live TV wiring (Jellyfin dashboard)

Point Jellyfin Live TV at this plugin: Dashboard → Live TV → TV Tuner → Add → M3U Tuner, URL — then add an XMLTV guide provider with URL . Refresh Channels first, then Refresh Guide, or the guide comes up blank. The themeable guide page is /RetroTv/Guide.

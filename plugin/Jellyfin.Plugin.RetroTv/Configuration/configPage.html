Retro TV

Turns the Internet Archive into a retro-video library and live channels inside Jellyfin. Video streams direct from the Archive at play time — nothing is downloaded to your server.

Getting started — do this first

The plugin alone does not put channels in Live TV. Follow these three steps — everything else on this page is optional and the defaults already work.

  1. Weather zip: if the zip below is not your town, change it, press Resolve zip, check the place name, then press Save at the bottom. Until you do this the weather channel has no location.
  2. Add the tuner: in the Jellyfin dashboard go to Live TV → TV Tuner → Add → M3U Tuner and paste the first link below. Then add an XMLTV guide provider with the second link. These two links are built from YOUR server's address — they are different on every install. Copy them from here, never from someone else's screenshot.
  3. Refresh Channels first, then Refresh Guide (Dashboard → Live TV). If you refresh the guide first it comes up blank.
  4. Make Jellyfin's own guide match: press Apply this theme to Jellyfin's Live TV guide next to the Guide theme below. One click writes the theme into Branding and keeps any CSS you already have. Without this, Jellyfin's guide shows no channel names.

Done right you should see 154 channels in Live TV with a programme guide up to 96 hours out. The themeable guide page is /RetroTv/Guide on this server.
